# avatar-shorts 大頭照動畫短影音

一個 Claude skill：用「你自己的表情大頭照」＋「你自己錄的旁白」，自動做出直式短影音。講到哪句換哪個表情，旁邊跳出道具，鏡頭推拉、轉場、音效、配樂、大字幕一次做好，看完跟 Claude 說「第 3 句換生氣」就幫你改。

- 直式 1080×1920、30fps、繁體中文
- 全部在自己電腦算，不用 GPU、不用付費 API
- 小學生也聽得懂的腳本口吻

## 五步流程

| 步驟 | 你要做的 | Claude 做的 |
|---|---|---|
| 1. 抓內容＋選風格 | 說這支想拍什麼、給誰看、要帶什麼產品，從 4 款風格挑一個 | 一題一題問清楚，整理成定位，依內容推薦風格 |
| 2. 做腳本 | 挑開頭、確認腳本 | 用 HOOK＋內容＋CTA、起承轉合寫好；給錄音稿 |
| 3. 給產品照 | 傳產品照和 2～3 個素材（第一次再做表情庫） | 放進對應的句子 |
| 4. 給錄音檔 | 照錄音稿念一遍，mp3、mp4 都可以 | 語音辨識自動切句、對上每一句 |
| 5. 含封面成片 | 看片、說哪裡要改 | 出 1080×1920 成片＋封面圖、自查規格／音量／安全區，改好重出 |

## 安裝

**Claude Code（電腦版）**：把這個資料夾放到 `~/.claude/skills/avatar-shorts/`。

**claude.ai（網頁／手機 App）**：用電腦打開 claude.ai → 設定 → 功能 → Skills → 上傳這個資料夾的 zip，並打開「程式碼執行」。之後手機 App 也能用。

需要 Python 3.9+、ffmpeg（`python scripts/setup.py` 會檢查並安裝 Pillow、numpy）。第一次對錄音會自動下載中文語音辨識模型（約 80MB）。

## 用法

跟 Claude 說「我要做大頭照動畫短影音」，它會一步一步帶你。

## 功能一覽

- 表情 14 種＋張嘴版（講話時自動對嘴）
- 運鏡 10 種：快速放大、震動、推近、拉遠、滑入、彈跳、搖擺、臉部特寫…
- 轉場：縮放穿越、百葉窗、色塊掃過、白光
- 道具 68 個（內建），也能放自己的圖
- 素材：截圖／照片／影片片段，卡片彈出或鋪滿畫面
- 設計感系列 10 款（柔霧奶茶／藍／綠／莓、瑞士極簡、瑞士拼貼、拍立得、撕紙、講解橘／藍）：人物在角落、字幕在人物旁邊，字不壓臉
- 另有拼貼風、6 款高級 IG 風、活潑卡通風；字型全部可商用（粉圓、思源宋體／黑體、DM Serif，OFL）
- 腳本庫：廣告思維（需要／想要／目的）、HOOK＋內容＋CTA、起承轉合、13 個模板，導演表自動檢查有沒有 CTA
- 配樂：內建 5 種風格（輕快、可愛、科技、溫馨、熱血，程式合成、可商用），講話時自動壓低
- 自查：規格、音量 -14 LUFS、黑畫面、空白、平台安全區
- AI 配音（備案）：Fish Audio、MiniMax、ElevenLabs、本機 GPT-SoVITS、微軟免費語音
