# 第 2 步：表情庫（用 ChatGPT 生一套自己的表情大頭照）

表情庫只做一次，之後每支片共用。放在工作資料夾 `faces/`。

## 最快做法：一張 4×4 表情總表 → 程式自動切 16 張

一次生成，角色長相最一致。在 ChatGPT（選有生圖的模型）：

### 步驟 1：上傳一張自己的正面清楚大頭照，貼這段

```
請根據我上傳的照片，畫一個代表我的卡通角色，保留我的髮型、臉型、眼鏡／飾品等特徵。
風格：【這裡換成下方「風格選項」其中一個】
構圖：只有頭和一點點肩膀，正面，置中。
背景：純白色，不要任何文字、不要邊框。
先畫一張「平常表情」給我確認。
```

不滿意就說「眼睛大一點」「頭髮再短一點」「更可愛一點」，滿意再做步驟 2。

### 步驟 2：同一個對話裡貼這段（順序不能改，程式照這個順序切）

```
很好！請用「完全一樣的角色」畫一張 4×4 的表情總表（共 16 格），正方形圖片。
每一格大小一樣、角色大小和位置一樣（頭和一點肩膀、置中），純白背景，格子之間不要線、不要文字、不要編號。
從左到右、從上到下依序是：
第 1 排：1 平常（嘴巴閉著）、2 平常（嘴巴張開在講話）、3 微笑（嘴巴閉著）、4 微笑（嘴巴張開在講話）
第 2 排：5 開心大笑、6 驚訝（嘴巴小小 O 型）、7 嚇到（眼睛瞪大、很誇張）、8 思考（眼睛往上看、手托下巴）
第 3 排：9 疑惑（皺眉、歪頭）、10 生氣（鼓臉、皺眉）、11 難過（快哭了）、12 眨一隻眼（調皮）
第 4 排：13 手指向旁邊（像在介紹重點）、14 比讚、15 得意（閉眼微笑、抬下巴）、16 揮手打招呼
```

### 步驟 3：下載圖片放進工作資料夾，跟 Claude 說「表情總表好了」

Claude 會跑：

```bash
python scripts/faces.py split 下載的圖.png faces/
```

自動切成 16 張、去白背景、統一大小，並輸出 `faces/_總覽.jpg` 給你檢查。切歪了（ChatGPT 有時格子不平均）就改用下面的「一張一張生」。

## 備案：一張一張生（格子切不好、或想要更高畫質）

每張都在同一個對話、接在步驟 1 後面：

```
用完全一樣的角色、一樣的構圖和大小、純白背景、不要文字，畫「【表情】」。
```

表情依序換成上面 16 個。下載後**用英文檔名**存進 `faces/`（中文檔名也認得）：

| 檔名 | 中文 | 什麼時候用 |
|---|---|---|
| neutral.png | 平常 | 一般說明 ★必備 |
| neutral_talk.png | 平常（張嘴） | 講話時自動切換，做出對嘴感 |
| smile.png | 微笑 | 友善、輕鬆 ★必備 |
| smile_talk.png | 微笑（張嘴） | 同上 |
| laugh.png | 大笑 | 好笑、成功 |
| surprised.png | 驚訝 | 「你知道嗎」 ★必備 |
| shocked.png | 嚇到 | 誇張反應、大數字 |
| think.png | 思考 | 提問、「為什麼」 ★必備 |
| confused.png | 疑惑 | 「蛤？」、常見誤會 |
| angry.png | 生氣 | 「不要再…」 |
| sad.png | 難過 | 痛點、失敗 |
| wink.png | 眨眼 | 小秘密、小技巧 |
| point.png | 指向 | 「重點來了」 |
| thumbsup.png | 比讚 | 推薦、CTA |
| proud.png | 得意 | 成果、「我做到了」 |
| wave.png | 揮手 | 開場、結尾掰掰 |

然後跑 `python scripts/faces.py cutout faces/ --same-box`（去背＋統一大小）。缺的表情會自動用相近的代替（例：沒有大笑就用微笑），但 ★ 四個一定要有。

## 風格選項（貼進步驟 1）

| 風格 | 貼這段 |
|---|---|
| Q 版 3D 公仔（最常見） | 3D 卡通公仔風，大頭小身體，皮膚光滑，柔和打光，像可愛的盒玩 |
| 日系動漫 | 日系動漫風，線條乾淨，大眼睛，賽璐璐上色 |
| LINE 貼圖風 | Q 版貼圖風，粗黑外框，平塗顏色，表情誇張 |
| 扁平插畫 | 扁平插畫風，簡單色塊，沒有陰影，現代感 |
| 水彩手繪 | 柔和水彩手繪風，溫暖色調 |

**不要**寫「迪士尼／皮克斯／吉卜力風格」這類公司或作品名，有版權疑慮，平台也可能拒絕生成。

## 檢查

```bash
python scripts/faces.py check faces/
```

看 `faces/_總覽.jpg`：每張角色大小差不多、背景透明（沒有白邊）、表情分得出來。白邊明顯就調 `--tol 50` 重跑 cutout；臉裡白色被挖掉就調小 `--tol 25`。

## 道具（可選）

內建 68 個道具（錢、燈泡、問號、鬧鐘、手機、獎盃……，清單見 `assets/props/props.json`，中文名也能用）。
想要自己的道具（店裡的商品、LOGO）：去背 PNG 放進工作資料夾 `props/`，導演表寫檔名（不含 .png）。也可以請 ChatGPT「畫一個○○的貼圖，透明背景」。
