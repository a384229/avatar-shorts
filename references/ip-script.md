# 第 1 步：IP 定位＋寫腳本

## A. IP 定位（第一次用才做，存成工作資料夾的 `ip.md`）

一次問一題，用聊天的方式，使用者回答越短越好，Claude 幫忙整理。

1. 你是誰？（一句話：職業／身分，例如「做烘焙 10 年的媽媽」）
2. 你想講給誰聽？（越具體越好：「剛出社會、月薪 3 萬的上班族」）
3. 他們最常煩惱什麼？（列 3 個）
4. 你能幫他們解決什麼？你的「獨門」是什麼？
5. 你的角色個性用 3 個詞形容（例：直白、好笑、像大姊）
6. 有沒有口頭禪或招牌開場／結尾？（例：「我是○○，今天教你一招」「學會了記得追蹤」）
7. 看完你的影片，你希望他們做什麼？（追蹤、私訊、買課、到店……只選一個主要的）

`ip.md` 格式：

```
# 我的 IP
- 我是：
- 講給：
- 他們的煩惱：1. 2. 3.
- 我能給：
- 角色個性：
- 口頭禪／招牌句：
- 主要行動（CTA）：
- 選題方向（Claude 依上面列 10 個，使用者勾）：
```

## B. 寫腳本規則（每支片）

**口吻：小學生也聽得懂。**
- 一句只講一件事，**一句 8～20 字**；超過就拆句（拆開剛好可以換表情）
- 不用專有名詞；非用不可就馬上用生活例子解釋（「複利，就是錢自己會生小錢」）
- 用「你」對觀眾說話，像跟朋友聊天；多用問句、數字、對比
- 數字、英文、破音字：台詞寫給字幕看，另外在導演表 `say` 寫「念法」（例：text「3 招」、say「三招」）

**長度：20～45 秒（約 90～200 字、8～16 句）**，第一支先做 30 秒。

**結構：**

| 段落 | 句數 | 要做的事 |
|---|---|---|
| 鉤子 | 1–2 | 0.5 秒內出大字＋表情，丟出問題或反常識 |
| 承諾 | 1 | 看完你會得到什麼（「3 招一次教你」） |
| 痛點 | 1–2 | 讓觀眾覺得「在說我」 |
| 重點 | 3–8 | 每個重點：一句結論＋一個生活例子；重點開頭用「第 1 招」→ 自動變成標籤 |
| 反轉／證據 | 1 | 數字、前後對比、真實案例 |
| CTA | 1 | 只要一個動作，用 IP 的招牌結尾 |

**開頭 10 型（先寫 3 個鉤子，挑最強的）：**
1 反常識（「90% 的人都做錯」）2 結果先行（「我 3 個月存到 10 萬」）3 痛點直擊（「存不到錢的人看過來」）
4 懸念（「最後一個最關鍵」）5 數字清單（「3 個方法」）6 身分標籤（「上班族必看」）7 對比（「月薪 3 萬 vs 10 萬的差別」）
8 情緒共鳴（「是不是只有我這樣」）9 直接動作（不廢話直接教）10 提問互動（「你會選 A 還是 B？」）

**不要：** 「哈囉大家好」、自我介紹開場、「今天要跟大家分享」、片頭 LOGO。

## C. 交給使用者確認的格式

```
片名：存錢順序錯了
開場大字：90%的人／都存錯錢（小標：上班族必看）　← 開頭型：1 反常識＋6 身分
1. 你是不是每個月都存不到錢？
2. 其實不是你賺太少
……
（共 9 句、約 25 秒）
```

使用者說 OK 才進第 4 步。腳本存成 `videos/片名/script.txt`（一行一句）。
