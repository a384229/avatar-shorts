# 第 1 步：IP 定位＋寫腳本

## A. IP 定位（第一次用才做，存成工作資料夾的 `ip.md`）

一次問一題，用聊天的方式，使用者回答越短越好，Claude 幫忙整理。

1. 你是誰？（一句話：職業／身分，例如「做烘焙 10 年的媽媽」）
2. 你想講給誰聽？（越具體越好：「剛出社會、月薪 3 萬的上班族」）
3. 他們最常煩惱什麼？（列 3 個）
4. 你能幫他們解決什麼？你的「獨門」是什麼？
5. 你的角色個性用 3 個詞形容（例：直白、好笑、像大姊）
6. 有沒有口頭禪或招牌開場／結尾？（例：「我是○○，今天教你一招」「學會了記得追蹤」）
7. 看完你的影片，你希望他們做什麼？（追蹤、私訊、買課、到店……只選一個主要的）

`ip.md` 格式：

```
# 我的 IP
- 我是：
- 講給：
- 他們的煩惱：1. 2. 3.
- 我能給：
- 角色個性：
- 口頭禪／招牌句：
- 主要行動（CTA）：
- 風格：（奶茶極簡／莫蘭迪綠／霧粉雜誌／黑金質感／霧藍清新／燕麥紙感／活潑）
- 選題方向（Claude 依上面列 10 個，使用者勾）：
```

## B. 寫腳本規則（每支片）

**口吻：小學生也聽得懂。**
- 一句只講一件事，**一句 8～20 字**；超過就拆句（拆開剛好可以換表情）
- 不用專有名詞；非用不可就馬上用生活例子解釋（「複利，就是錢自己會生小錢」）
- 用「你」對觀眾說話，像跟朋友聊天；多用問句、數字、對比
- 數字、英文、破音字：台詞寫給字幕看，另外在導演表 `say` 寫「念法」（例：text「3 招」、say「三招」）

**長度：20～45 秒（約 90～200 字、8～16 句）**，第一支先做 30 秒。

**結構、開頭 10 型、塞肉、CTA、13 個模板：全部照 `references/script-library.md`**（HOOK → 內容 → CTA，用起承轉合排節奏，先寫需要／想要／自己的目的三句）。

## C. 交給使用者確認的格式

照 script-library.md 最後的格式（模板、三句、HOOK 型、CTA 型、【起承轉合】分段）。使用者說 OK 才往下。腳本存成 `videos/片名/script.txt`（一行一句，用【起】【承】【轉】【合】分段）。
