# 功效怎麼講：只用官方可以講的說法＋白話包裝

**原則：**
1. 只用衛福部公告「可以使用」的說法，**白話版不能比官方原句講得更多**。例如官方說「改善暗沉」，白話可以說「氣色看起來比較亮」，但不能說「一週變白」。
2. 說法要**符合這個產品真的有的東西**：營養素的說法，產品裡要真的有那個營養素；保養品的說法要有佐證（試驗、成分）。不確定就問使用者，或改講使用習慣。
3. 片中不露品名、包裝（見 SKILL.md 第 3 步），但**講功效的規則一樣適用**，私訊裡也一樣。
4. 先問清楚是**食品（吃的、喝的、錠狀、粉末）**還是**化粧品（擦的、敷的、彩妝）**。兩邊能講的不一樣，同一個詞（例如「美白」）可能一邊可以、一邊不行。

---

## 一、化粧品（保養品、面膜、彩妝）

依據：《化粧品標示宣傳廣告涉及虛偽誇大或醫療效能認定準則》，2019-07-01 施行，附件二「得宣稱詞句」。

| 產品 | 官方可以講的說法（原句） | 白話包裝（照這個意思講） |
|---|---|---|
| 化粧水、乳液、面霜、凝膠、面膜 | 保濕、補水、鎖水、水嫩 | 擦完臉不會緊繃／摸起來水水的／冬天也不會乾到脫皮 |
| 同上 | 防止肌膚粗糙、預防乾燥、舒緩肌膚乾燥 | 臉摸起來比較滑，不會粗粗的 |
| 同上 | 柔白、亮白、嫩白、美白、改善暗沉 | 膚色看起來比較透亮／氣色看起來比較亮（要有佐證） |
| 同上 | 延緩肌膚老化、淡化細紋、飽滿（彈力）肌膚 | 保養要趁早／細紋看起來比較不明顯／摸起來有彈性 |
| 同上 | 肌膚清爽、清涼感 | 擦起來清爽不黏 |
| 洗面乳、卸妝 | 清潔肌膚、去除髒汙、去角質、通暢毛孔 | 洗完很乾淨、不緊繃／毛孔看起來比較乾淨 |
| 粉底、粉餅、蜜粉 | 修飾美化膚色、遮蓋斑點／痘疤／黑眼圈、均勻膚色 | 上了妝，斑和痘疤都蓋得住／膚色看起來很勻 |
| 同上 | 增添肌膚光澤、提亮膚色、粧感好氣色 | 上妝後氣色很好，看起來有光澤 |
| 唇膏、唇蜜 | 滋潤嘴唇、防止嘴唇乾裂 | 嘴唇不會乾到裂開 |
| 眼妝 | 使睫毛有濃密纖長感、放大眼神 | 睫毛看起來又長又密，眼睛變有神 |
| 洗髮、護髮 | 清潔頭皮、使頭髮柔順、修護毛躁髮質 | 頭髮變好梳、不毛躁 |

**化粧品不能講：** 治療、消炎、殺菌、除痘、除疤、消除黑眼圈或眼袋、換膚、生髮、瘦身、消脂、豐胸、消除浮腫、促進膠原蛋白合成、活化毛囊、零過敏、醫藥級、漂白、雷射級；任何「治好、根治、永久」。

## 二、食品、營養補充品（吃的、喝的、錠狀、粉末）

依據：《食品及相關產品標示宣傳廣告涉及不實誇張易生誤解或醫療效能認定準則》第四條：附件一「通常可使用之詞句」、附件二「營養素或特定成分之生理功能詞句」不算違規。下表的原句取自 101 年版認定表；**113 年版附件可能有調整，正式使用前請對照全國法規資料庫的最新附件**（https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0040140）。

**通常可以講的說法（任何食品）**

| 官方原句 | 白話包裝 |
|---|---|
| 營養補給、健康維持 | 三餐吃不夠，用它補一下 |
| 調整體質、調節生理機能、促進新陳代謝 | 讓身體作息比較規律 |
| 幫助消化、幫助維持消化道機能、使排便順暢 | 吃完比較不會脹／每天上廁所比較順 |
| 養顏美容、青春美麗 | 從裡面開始保養 |
| 增強體力、精神旺盛、滋補強身 | 我覺得每天比較有精神（講自己的感受） |
| 幫助入睡 | 我把它當睡前的固定儀式 |
| 清涼解渴、生津止渴、潤喉、促進食慾 | 喝起來很解渴／很開胃 |
| 產前產後或病後之補養 | 坐月子、生病後補一補 |

**營養素可以講的生理功能（產品裡要真的有這個營養素，並講明是「這個營養素」的作用）**

| 營養素 | 官方原句 | 白話包裝 |
|---|---|---|
| 維生素 C | 促進膠原蛋白的形成；促進鐵的吸收 | 維生素 C 會幫身體做膠原蛋白 |
| 維生素 D | 增進鈣吸收 | 維生素 D 幫鈣吸收 |
| 鈣 | 有助於維持骨骼與牙齒的正常發育及健康 | 鈣是骨頭和牙齒的材料 |
| 鐵 | 有助於正常紅血球的形成 | 鐵是做紅血球需要的 |
| 鋅 | 增進皮膚健康 | 鋅跟皮膚健康有關 |
| 維生素 A、β-胡蘿蔔素 | 有助於維持在暗處的視覺 | 暗的地方比較看得清楚 |
| 膳食纖維 | 可促進腸道蠕動、增加飽足感、使糞便比較柔軟而易於排出 | 比較有飽足感、上廁所比較順 |

**食品不能講：** 美白、變白、淡斑、改善膚質、除痘、抗老、延遲衰老、防止老化、改善皺紋、瘦身、減肥、纖體、塑身、豐胸、增高、增強抵抗力（免疫力）、排毒、改善更年期、經痛或生理痛改善、降血壓、降血糖、改善過敏、治療任何病；「健康」放在品名裡（取得健康食品許可的除外）。

## 三、使用者常問的詞，怎麼改

| 夥伴想講 | 能不能講 | 改成 |
|---|---|---|
| 變白 | 食品不行；保養品可以（美白、亮白、改善暗沉，要有佐證） | 食品：講習慣、口味。保養品：「膚色看起來比較透亮」 |
| 變美 | 食品可用官方句「養顏美容、青春美麗」；保養品講妝感、光澤 | 「從裡面開始保養」／「上妝後氣色很好」 |
| 經痛改善 | **都不行**（醫療效能，罰最重） | 只講習慣：「生理期那幾天，我會固定喝一杯熱的○○」，不說改善了什麼 |
| 痘痘變少 | 都不行 | 彩妝可以說「遮得住痘疤」；保養品講「洗完很乾淨、不緊繃」 |
| 變瘦 | 都不行 | 膳食纖維可講「比較有飽足感」 |
| 睡得好 | 食品可用「幫助入睡」 | 「我把它當睡前的固定儀式」 |
| 喝了皮膚從這樣變這樣（BA 照） | 都不行（食品改變外觀＋前後對照） | **BA 改成比生活習慣**：「以前睡前一杯紅酒 → 現在換成這杯，一樣的杯子、一樣的儀式感」，同角度拍前後兩個畫面；再接「從裡面開始保養」 |
| 有精神 | 食品可用「精神旺盛、增強體力」 | 講自己的感受，不講數字、不保證 |

**「從這樣，變成這樣」開頭（于葳定案的對比句型）：** 台詞只說「我從這樣……變成這樣」，畫面負責對比。畫面只能比**生活習慣、場景、心情**（睡前那杯紅酒 → 同一個杯子換成這杯；以前下午一杯手搖 → 現在下午泡這杯；以前保養七層 → 現在三步），**不能比皮膚、身材、體重**（畫面也算宣傳，皮膚 BA 照一樣違規）。兩個畫面同角度、同構圖，切換時用快轉場。**前後的生活場景一定要照使用者真的怎麼用（第 4 題「怎麼排進一天」的答案）**，上面只是舉例，不要自己編用法；不知道就先問。**粉狀沖泡的不要寫成配飯、跟餐一起喝**（照產品說明的時間喝，通常是空腹或兩餐之間，以使用者說的為準）。

**白話包裝的寫法：** 用生活畫面講（「冬天也不會乾到脫皮」比「高效保濕」好懂），一句只講一件事，不加「超級、立刻、保證、一定、永久」，不放前後對照。

這份是一般法規整理，不是法律意見；美安公司若有自己的廣告規範，以公司的為準。
